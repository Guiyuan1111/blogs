## 一、AI 发布文章的完整路径（实测）

### 1.1 总体流程

```
本地 Markdown 文章
→ ① 转换为站内编辑器格式（marked + Prism，见 1.3）
→ ② 打开创建页 /spaces/{id}/resources/new?type=online
→ ③ 填标题（≤50字）→ 贡献摘要（≤150字）→ 选所属目录 → 点推荐标签
→ ④ 正文写入编辑器（TinyMCE setContent + Vue 数据模型同步）
→ ⑤ 点「创建」→ 跳转 /resources-docs/{资源id} 完成发布
```

### 1.2 路径中的关键技术点

1. **编辑器是 TinyMCE 5.9.2（Vue 包装）**。有个隐蔽的坑：调用 `setContent()` 只改变编辑器显示，**不会同步**前端真正用于提交的 Vue 数据模型（`form.content`）——只做这一步，发布出去的是旧内容/模板。必须同时把 HTML 写入组件数据模型，表单提交才有效。
2. **保存/创建的最终请求**：`POST /v1/products/{空间id}/pull_quests`，正文 HTML 位于请求体 `pull_quest_items[0].content`（嵌套结构，不在顶层）。
3. **标签**：只能从平台推荐的标签池中点选，直接输入自定义文字不生效。
4. **所属目录**：必填项，需在弹窗中手动选择节点（本次选了「根目录」）。

### 1.3 逆向出的站内容格式规范（已整理成文档）

- 代码块存储格式：`<pre class="language-x">…Prism 高亮标签…</pre>`（无内层 `<code>`），与编辑器「插入/编辑代码示例」按钮的产物一致；
- Markdown 迁移映射：代码围栏 → 上述结构（语言别名 bat→batch 等）；GitHub 提示框（`> [!WARNING]` 等）→ 彩色标签；正文剥离首个 H1 进独立标题字段。

## 二、路径中遇到的障碍（对 AI 不友好的点）

按实际遇到顺序：

1. **标题 50 字上限在提交时才报错**。AI 从文章 H1 生成的标题天然偏长（实测 66~83 字），填完一整篇、点创建才收到"标题不能超过50个字"，前功尽弃。
2. **校验错误只在点创建时集中出现**（标题超长、未选目录同时才暴露），无法提前感知。
3. **表单会被页面异步重渲染清空已填内容**（实测标题填好后被清空过一次）。
4. **「资源类型」无稳定默认值**：一次打开默认选中"原创"，另一次打开为空导致提交被拦。
5. **悬浮元素遮挡按钮**：固定顶栏与底部悬浮操作条使自动化点击频繁超时，只能降级为 DOM 直点。
6. **正文写入编辑器 ≠ 内容被提交**（见 1.2 第 1 条），这是整条路径里最大的隐蔽坑。
7. **代码高亮标签被服务端剥离**：即使内容里带完整的 `<span class="token">` 高亮结构（与编辑器自带工具产物一致），保存后也被剥成黑白纯文本。老文章（如 35661）的颜色是早期版本入库保留的；现在新发布一律无高亮，**老文章重新编辑保存也会永久丢失颜色**。

## 三、优化建议：让知士荟更适合 AI 提交文章

按价值排序：

### ① 提供 Markdown 直传的官方发布方式（价值最大）

允许直接提交 Markdown 原文（接口或编辑器"导入 Markdown"入口均可），由平台侧统一做格式转换。好处：

- AI 不必逆向编辑器存储格式，转换逻辑由平台官方维护，永远不会"格式不对"；
- 表格、代码语言、提示框的渲染效果由平台掌控，风格统一；
- 现有大量技术用户（CTF/教程写手）的稿件天然是 Markdown，接入成本极低。

### ② 保留代码块高亮标签

入库净化建议改为白名单：对 `pre[class*="language-"]` 内部的 `span`，保留值为 Prism token 类名的 `class` 属性，仅过滤危险属性。这样代码示例工具生成的颜色能存得住，老文章重存也不再丢色。

### ③ 校验前置、实时反馈

标题 50 字、目录必选、摘要 150 字等规则，在输入框旁实时提示（字数计数器 + 即时校验），而不是等点创建才集中报错。对 AI 和普通用户都更省事。

### ④ 给出合理的默认值

「资源类型」固定默认"原创"；所属目录单目录空间可默认根目录/唯一目录。减少一次交互就少一个出错点。

### ⑤ 提供发布回执

创建成功后返回结构化结果（资源 id / 最终 URL）。自动化场景下能可靠地确认落地页，也方便用户收藏。

### ⑥ 题图/封面的外链支持

沙箱化环境（含很多 AI 运行时）无法操作本地文件选择框。若题图/封面支持直接填图片 URL，AI 就能把题图也配齐。
