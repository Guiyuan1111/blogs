## 3. 基础设施与防护观察

- **三域名分工**：`www`（SPA 入口，1856 字节壳页面）/ `vue`（静态资源）/ `api`（后端服务），前后端分离。
- **机器人识别头**：响应头带 `X-Is-Bot: 0`，说明入口层有 bot 判定逻辑（当前会话被判定为正常浏览器）。
- **SPA 兜底路由**：不存在真实的 `robots.txt`（该路径返回首页 HTML）；`/sitemap.xml` 同样返回 200（SPA 兜底）。对搜索引擎的收录指引实际由入口层控制。
- **`/py/api/` 前缀**：存在独立的 Python 服务集群（活动贡献统计、激励奖励等），与主 API（`/v1`、`/v2`）分治。

## 4. API 概览（仅列本人会话中实际观察到的端点）

| 端点 | 用途 |
| :-- | :-- |
| `POST /v1/products/{空间id}/pull_quests` | 资源创建/更新（`pl_action: create\|update`），正文在 `pull_quest_items[0].content` |
| `GET /v1/products/{空间id}/count` | 空间计数 |
| `GET /v1/products/{空间id}/product_files/{资源id}` | 资源详情 |
| `GET /v2/product_files/{资源id}/siblings` | 同空间资源列表 |
| `GET /v1/comments?commentable_type=ProductFile&…` | 评论 |
| `GET /v1/users/{用户id}` | 用户公开信息 |
| `POST /v2/statistics` | 浏览统计上报 |
| `GET /py/api/activities/contributions/` | 贡献活动记录 |
| `GET /py/api/incentive/rewards/summary/` | 激励/奖励汇总 |
| `GET /py/api/recommendations/resources/` | 相关推荐 |

请求为 XHR + JSON 字符串体；会话鉴权依赖 Cookie。

## 5. 功能面（从导航与界面枚举）

- **空间内模块**：主页 / 动态 / 资源 / 讨论 / 习题 / 卡片 / 公告 / 分析 / 设置。
- **可创建的资源类型**（新建下拉）：在线文章、上传视频、图文笔记、思维导图、试卷、卡片。
- **编辑器增强**：代码示例（Prism 高亮）、LaTeX 公式、内链、锚点、思维导图、AI 润色（"润色结果"对话框）、表情/特殊符号、附件（≤100MB）。
- **激励体系**：贡献（贡献标题/摘要）、奖励汇总接口、总奖励展示、"推荐到主页/加精"内容运营动作。
- **社区**：关注/点赞/收藏/评论、通知四类（评论回复、收到的赞、新增关注、系统通知）、站内信（/letters）、QQ 群。

## 8. 站外信息与社区生态（2026-09-17 检索）

### 8.1 平台定位与用户群（外部视角）

- 官方自述为**"软件工程课程体系学习社区"**，主打高校课程场景：课程通过"学习空间"接入，教师发布资源/公告，学生在讨论区答疑、做习题；
- 已知高校落地案例：**国防科技大学**——研究生课程《深度学习》空间（id 3578）、《软件工程》课程体系、"C/C++ 程序设计"空间（引入 AI 虚拟助教答疑）；
- 平台整体外部声量极低：CSDN/知乎/博客园等主流技术社区**没有**找到任何使用教程、经验帖或评测。

### 8.2 值得站长注意的两个外部痕迹

1. **预发环境公开可达且被搜索引擎收录**：搜索结果中存在 `staging.learnerhub.net`（实测返回 200）。staging 环境出现在公开搜索结果通常并非有意为之，建议评估：加 `X-Robots-Tag`/robots 屏蔽、或加访问控制。此条可作为附加建议并入给站长的报告。
2. **第三方集成曾存在、现已消失**：GitHub 上曾有 `cyan-io/learner-board`（面向教师/助教的知士荟 issue 看板），现仓库 404（删除或转私有），Wayback Machine 无存档。说明存在过第三方开发者的集成需求——与"官方 API/Markdown 直传"建议互相印证。

### 8.3 官方开源痕迹

- Gitee 组织 [`gitee.com/learnerhub`](https://gitee.com/learnerhub)：仅 2 个公开仓库——`jenkins-shared-library`（佐证平台使用 **Jenkins** 做 CI/CD）与 `javatest`（Java 测试）；组织简介未填写，成员 2 人。

### 8.4 同名干扰项（避免误判）

- GitHub 搜索 "learnerhub" 共 29 个同名仓库，绝大多数为无关项目（印度教育平台、课程作业等）；
- `SlightLan/LearnerhubLearningNote`、`SlightLan/LearnerhubDoc`（2018 年，"开发 LearnerHub 的经历"）实为**基于 GitLab 的同名老项目**（内容为 GitLab/Ruby/PostgreSQL 部署笔记），与知士荟无关；
- `cyan-io/learner-board` 是检索中唯一确认与知士荟相关的第三方项目（已消失）。

### 8.5 备案主体

`湘ICP备20002562号-1` 为湖南备案、编号格式对应 2020 年前后；备案主体名称需在 [MIIT 备案系统](https://beian.miit.gov.cn/)、[站长工具](https://icp.chinaz.com/) 或[天眼查](https://beian.tianyancha.com/)查询（搜索引擎不直接返回结果）。
